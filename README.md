# Анима

> **Анима — это** локальный ИИ-компаньон с суверенной памятью: цифровое существо, которое живёт одним файлом на вашем диске, учится на скармливаемых файлах без облака и без дообучения языковых моделей, отвечает строго из накопленной памяти (а не выдумывает), а свои фантазии не подавляет, а измеряет — считается, сколько её идей попало в ваш вкус. Языковая модель здесь — сменный «голос», а не мозг: память принадлежит владельцу и переживает смену модели, сервиса или интернета.

## Быстрый старт (5 минут)

Нужен только Python 3.8+. Все зависимости — стандартная библиотека, ничего устанавливать не надо.

```bash
# 1. Склонируйте или скачайте репозиторий, все файлы — в одну папку

# 2. Проверьте окружение
python anima_setup.py        # пункт 1 — проверка окружения

# 3. Играйтесь на демо-памяти (без своих данных)
python anima_setup.py        # пункт 3 — установка демо-памяти

# 4. Запуск через защищённый лаунчер (скан секретов + пароль на память)
python anima_launcher.py

# Альтернатива: прямой запуск ядра
python Anima.py
```

Поиск по памяти можно проверить и без окна, из командной строки:

```bash
python anima_semantic.py "сны питомца" demo_memory.json
```

## Файлы проекта

| Файл | Назначение |
|---|---|
| `Anima.py` | ядро v5: память, кормление, ответы, сны, эмоции, настроения, Study Engine, окно питомца (tkinter) |
| `pet_agent.py` | ранняя версия ядра (v3), сохранена для истории развития проекта |
| `anima_semantic.py` | смысловой поиск: TF-IDF по словам, тегам и 3-граммам; нейроэмбеддер — опция; есть CLI-режим |

| `anima_launcher.py` | защищённый запуск: скан секретов, пароль на память, обратное шифрование при выходе |
| `anima_setup.py` | установщик: проверка окружения, чистка секретов, установка демо-памяти |

| `precommit_check.py` | проверка перед пушем: ловит секреты и личные файлы до коммита |
| `habr_post.md` | текст статьи о проекте |

## Что умеет ядро (v5)

- **Кормление файлами**: текст, код, CSV, JSON, ZIP, логи — Анима разбирает на факты и запоминает в один файл `pet_memory.json`. Это душа питомца — не удаляйте его.
- **Вопрос-ответ из памяти**: отвечает строго по накопленному. Не знает — честно говорит «не знаю».
- **Сны-грёзы**: спаривает факты из разных источников в неожиданные связки. Эстетика снов зависит от настроения (при низком — рваные, с многоточиями) и близости к владельцу.
- **Reality Filter**: каждый сон сверяется с памятью — вы подтверждаете или отвергаете связку.
- **Измерение фантазий**: команда «эксперимент» показывает, сколько снов попало в ваш вкус — в цифрах.
- **Эмоциональный резонанс**: тональность съеденных данных двигает настроение и копит стресс. Мрачные данные → мрачные сны, радостные → игривые.
- **Два режима мышления**: «исследователь» (сны почти выключены) и «провидец» (фантазии активны) — переключение командой `/режим`, автоматически при парадоксе или стрессе.
- **Локус контроля**: при высокой фантазии питомец сам инициирует исследование; при стрессе сам предлагает «что-то светлое» из вашей памяти.
- **Карантин фактов**: сомнительный факт не попадает в ответы, пока не пройдёт проверку. Доверие растёт с подтверждениями, два наказания подряд — карантин.
- **Study Engine**: две фазы обучения — «поэзия» (мосты между фактами) и «математика» (числа, паттерны, прогноз).
- **Рост**: уровни от 🥚 Яйца до 🦅 Взрослого помощника — питомец растёт от кормления и общения.

## Существующие аналоги и отличия

Жанр «локальный ИИ-компаньон» живой, честно перечисляю близкие проекты:

- **[Nova-Core](https://github.com/Nikil0g/Nova-Core---Local-AI-Companion-System)** — локальный компаньон с долгосрочной памятью и личностью;
- **[Project N.E.K.O.](https://project-neko.cn)** — компаньон, который «слушает, видит и помнит», локальный голос;
- **[memU](https://crewclaw.com/openclaw-vs-memu-ai-agent-framework-vs-personal-ai-companion-2026)** — персональный ИИ, память в файлах, децентрализованная архитектура;
- **Miru, ECHO, QwenPaw, Jarvis, Capri, PawPal** — локальные ассистенты с памятью на Ollama и векторных БД.

| Компонент | Аналоги | Анима |
|---|---|---|
| Локальный компаньон с памятью | да | да |
| Память в файле у владельца | да (memU, Jarvis) | да |
| LLM как опция, без неё работает | частично | да |
| Карантин фактов + «доверие двух ударов» | нет прямых аналогов | да |
| Измеримая фантазийная ветвь (сны + Reality Filter + счёт попадания) | не встречено | да |
| Рост через «кормление» (геймификация памяти) | редко, по кусочку | да |
| Эмоции, настроение и связь с владельцем, влияющие на поведение | частично, у отдельных проектов | да |
| Ноль зависимостей как принцип | почти нет (обычно ChromaDB, векторы) | да |

Архитектурное отличие: у аналогов память — модуль внутри ассистента; в Аниме память — само существо, а ассистент — его проявление.

## Безопасность

- **Маска секретов на входе**: токены и ключи маскируются при кормлении (`anima_secure.py`).
- **Шифрование памяти**: PBKDF2-HMAC-SHA256 (200k итераций) + HMAC, стандартная библиотека. Честно: это не AES — заглушка до релиза, план — AES-GCM.
- **Скан секретов при запуске**: лаунчер проверяет файлы проекта перед стартом.
- **Пока Анима запущена**, расшифрованная память лежит на диске открытым текстом — так работает любое шифрование «на диске».
- Секреты (ключи, пароли, персональные данные) не кормите в память — как не кладут их в публичные репозитории.
- `pet_memory.json` и `.env` защищены `.gitignore` и `precommit_check.py` — не отключайте их перед пушем.

## Ограничения (честно)

- Словарный поиск ловит морфологию и опечатки, но не синонимы (без нейроэмбеддера);
- Вся ценность проверена на одном пользователе — авторе; на чужих сценариях не тестировалась;
- Нет прав доступа, журналов, многопользовательской модели — для корпоративного контура надо наращивать;
- Нет голоса, аватара, интеграций;
- Один файл памяти — точка отказа: делайте резервные копии;
- Речь без подключённой LLM шаблонная — модель опциональна и сменна, память от неё не зависит.
